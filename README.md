# Elektrik Yük Hesabı

Mobil uyumlu, statik web uygulaması. GitHub Pages üzerinden yayınlanabilir.

- `index.html`: uygulama ve arayüz
- `xlsx.full.min.js`: Excel dışa aktarma
- `manifest.webmanifest`, `sw.js`: ana ekrana ekleme ve çevrimdışı önbellek

Siteyi yayımlamak için GitHub Pages kaynağını `main` dalı ve `/ (root)` olarak ayarlayın. GitHub Pages sitesi herkese açıktır.
